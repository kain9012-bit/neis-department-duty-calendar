# NEIS Department Duty Calendar

나이스 월간일정 화면에서 부서 구성원의 복무현황을 확인할 수 있도록 돕는 Chrome·Edge 확장 프로그램입니다.

## 개인정보처리방침

[개인정보처리방침 보기](https://kain9012-bit.github.io/neis-department-duty-calendar/)

## 설치

1. 이 저장소를 내려받습니다.
2. Chrome 또는 Edge의 확장 프로그램 관리 화면에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 선택하고 이 폴더를 지정합니다.

자세한 사용 방법과 변경사항은 `README.txt`를 참고하세요.
